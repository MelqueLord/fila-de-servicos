# Status do projeto

## Fase atual

Cadastro, listagem, busca, filtro, alteração de status, edição, exclusão com
confirmação e PWA estão concluídos. A próxima etapa é integrar o Supabase para
cadastro, login e armazenamento das ordens na nuvem, garantindo que cada
usuário acesse somente as próprias ordens.

## Próximo passo

Preparar a autenticação e o banco de dados no Supabase, mantendo o app em HTML,
CSS e JavaScript e a publicação no Netlify.

## Fora do escopo desta versão

Pagamentos e integrações externas além do Supabase.
