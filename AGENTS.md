# AGENTS.md

## Regras de trabalho

- Use apenas HTML, CSS e JavaScript simples.
- Use Supabase para cadastro, login e banco de dados das ordens.
- Cada usuário deve acessar somente as próprias ordens.
- Não crie pagamentos ou integrações além do Supabase.
- Mantenha o app publicado no Netlify.
- Priorize celular, acessibilidade e instalação como PWA.
- Antes de excluir uma ordem, peça confirmação.
- Mantenha o código simples, organizado e em português quando fizer sentido.
